# Homebrew Tap

Homebrew formulae and casks for [MakLock](https://github.com/dutkiewiczmaciej/MakLock) and other tools by [Maciej Dutkiewicz](https://github.com/dutkiewiczmaciej).

## Install

```bash
brew tap dutkiewiczmaciej/tap
brew install --cask maklock
```

## Available Casks

| Cask | Description |
|------|-------------|
| `maklock` | Lock apps with Touch ID, Apple Watch, or password |
